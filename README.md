# gp--learn

玉米基本面截面 GP 因子挖掘框架

## 项目简介

利用遗传规划（Genetic Programming）在每日截面数据上搜索特征数学组合，预测玉米期货未来 N 日收益率。

## 数据来源

- 基本面数据：`国内玉米基本面日度数据_副本.xlsx`（每行 = 一个日期截面，包含北港/珠三角价格、仓单、到货量、深加工收购价等 20+ 维特征）
- 价格数据：`corn_en_no_oi.txt`（玉米期货日线 OHLCV）

## 特征体系

| 类别 | 特征数量 | 说明 |
|------|---------|------|
| 原始特征 | ~10 | 现货价格、仓单、到货量、车辆等 |
| 价差类 | ~5 | 南北价差、价比、仓单/到货量比 |
| 动量类 | ~16 | 3/5/10/20 日收益率、涨跌方向 |
| 变化率类 | ~12 | 仓单/到货量变化量及变化率 |
| 分位数/标准化 | ~3 | z-score20 |
| 均线乖离率 | ~6 | MA5/MA20 乖离、均线交叉信号 |
| 复合派生 | ~5 | 小麦替代成本动量等 |

## 方法论

- **GP 树结构**：支持 add/sub/mul/div/abs/sqrt/log/max/min 等操作符
- **适应度**：60 天滚动窗口 IC（Spearman 秩相关）均值
- **遗传操作**：锦标赛选择 + 单点交叉 + 子树变异 + 精英保留
- **验证**：5 折滚动时间序列交叉验证

## 运行

```bash
python gp_corn.py
```

## 输出

- 最优因子公式（可读数学表达式）
- IC Mean / IC 指标
- 样本外 IC 均值、标准差、胜率
